# 奧客互助協會

附近餐廳出現奧客 → 店員一鍵求救 → 方圓 500 公尺的勇者接任務 → 店員確認後發獎勵代碼。

- 創意發起人：Popcorn
- 程式美編設計：Kama

## 檔案

| 檔案 | 用途 |
|---|---|
| index.html | 畫面（點陣風 UI） |
| avatar.js | 奧客外觀點陣人物：選項、繪圖、編輯器 |
| app.js | 全部邏輯：定位、通知、地圖、任務、離線佇列 |
| config.js | **唯一要改的檔**：Google Maps 金鑰、Firebase、範圍 |
| sw.js | Service Worker：離線快取、通知點擊 |
| manifest.webmanifest + icons/ | 加到主畫面用 |

## 上線（GitHub Pages，免費、自帶 HTTPS）

定位、通知、Service Worker 都**必須是 HTTPS**，直接雙擊 index.html 不會動。

1. GitHub 開新 repo（例：`kamaJe122/ok-bye-Association`），把整個資料夾上傳
2. Settings → Pages → Branch 選 `main` / `root` → Save
3. 約 1 分鐘後網址：`https://kamaje122.github.io/ok-bye-Association/`

## 兩種模式

- **示範模式（預設）**：資料存在本機，同一台裝置開兩個分頁就能模擬「店員」和「勇者」。
- **雲端模式**：在 config.js 填 `FIREBASE`（Realtime Database，免費 Spark 方案），所有人即時同步。

## Google Maps 金鑰

1. Google Cloud Console → 建立專案 → 綁帳單帳戶（要信用卡）
2. 啟用 **Maps JavaScript API**
3. 憑證 → 建立 API 金鑰 → 應用程式限制：**HTTP 參照網址** `https://kamaje122.github.io/*`
4. 配額 → Maps JavaScript API → Map loads per day 設 **300**（保險絲，超過就停，不會被扣錢）
5. 金鑰貼到 config.js 的 `GMAPS_KEY`

沒填金鑰也能用：會顯示免費的真實街道地圖（OpenStreetMap 資料，可拖拉、縮放），離線時自動切換成內建「點陣雷達」。

## 店家／勇者身分（v1.3.0）

右上角的「勇者／店家」標籤，或「我的」分頁，都可以切換身分。

| 步驟 | 誰 | 做什麼 | 狀態 |
|---|---|---|---|
| 1 | 店家 | 在「我的」填店名 → 「求救」發出任務（可畫奧客長相） | 求救中 |
| 2 | 勇者 | 在「我的」設定綽號＋長相 → 「任務」按接任務 | 勇者前往中 |
| 3 | 店家 | 收到通知，看到勇者的綽號和長相 | |
| 4 | 勇者 | 處理完按「回報任務完成」，可附訊息（有快速句） | 待店家確認 |
| 5 | 店家 | 「確認完成並發獎勵」或「還沒解決」（退回步驟 4），可回覆勇者 | 已解決 |
| 6 | 勇者 | 收到兌換碼，放進「背包」 | |

- 同一支手機的店家和勇者是兩個不同身分，示範模式下可以一個人切換身分測完整流程。
- 示範店家的任務在你回報後 3 秒會自動確認。
- 雲端模式用 Firebase transaction 防止兩個勇者同時接到同一個任務。

## 店家地址與點陣招牌（v1.5.0）

店家在「我的」可以：
- **上傳 Logo**：自動裁成正方形、轉成點陣圖（粗 12 格／中 16 格／細 24 格），存在手機。
- **設定地址**：輸入地址按「搜尋地址」（OpenStreetMap Nominatim，免費免金鑰；找不到門牌會自動退到路名），或在店門口按「用我現在的位置」。

發求救時，任務會標在店家地址（沒設定才用手機定位），地圖上立起店家的點陣招牌，招牌上方是 RPG 任務符號：

| 符號 | 意思 |
|---|---|
| ！（黃，會上下跳） | 有任務，等勇者接 |
| …（藍） | 勇者前往中 |
| ？（黃） | 勇者回報完成，等店家確認 |
| ✓（綠） | 已解決 |

招牌右下角的火焰大小代表奧客等級，右邊站著奧客的點陣人物。

**奧客卡牌**（「我的」→ 奧客卡牌，或任務卡上「做成奧客卡牌」）：
- 綽號、星等（N／R／SR／SSR／UR）、最多 4 個技能（會依事蹟自動建議）、事蹟、地點、時間、點陣人物
- 輸出 720×1008 卡牌圖，用手機分享面板傳給朋友；不支援的裝置會下載圖片
- 卡牌存在手機裡；為了隱私，擋掉電話、帳號、長串數字
